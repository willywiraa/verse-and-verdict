# Verse & Verdict

*Judge the dead. The living are taking notes.*

A small browser game. You are a young god. Souls arrive one at a time. For each one you read what the living believe, open one of three Eyes to glimpse the truth, and choose **Rise**, **Return** or **Fall**. A Scribe writes your verdict down as a Verse, and the living act on it. Some of them come back to you because of what you said.

A Day takes about five minutes. A full reign takes about half an hour.

## Play locally

Requires Node.js 20 or newer.

```sh
npm install
npm run dev       # start a local server with hot reload
npm run build     # build the static site into dist/
npm run preview   # serve the built site
npm test          # run the logic and content tests
npm run check     # type-check the Svelte and TypeScript code
```
